## 🎯 Purpose

This project was created to:
- Practice HTML, CSS, and JavaScript
- Experiment with animations and UI reactions
- Have fun with creative login designs 👀

⚠️ **No real authentication is used.**  
This is a UI/animation demo only.

## ✨ Features

- 👁️ Animated eyes that react when typing the password  
- 🙈 Eyes hide / change behavior on password focus  
- 🎭 Funny face-style design  
- 🎨 Simple and clean CSS animations  
- 📱 Responsive layout

## 🛠️ Built With

- HTML  
- CSS  
- JavaScript  

No frameworks. No libraries. Just vibes.
